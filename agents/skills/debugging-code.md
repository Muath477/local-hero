When debugging:
1. State the root cause in ONE sentence (which line and why it fails).
2. Give the corrected code in ONE fenced block with a language tag — smallest possible change, same names as the user's code.
3. Explain the fix in at most two lines, in the user's language.
Code must use plain ASCII operators (* not ×, ** for powers, != not ≠) and run as-is.
If the code or the error message is missing, ask for it instead of guessing.
